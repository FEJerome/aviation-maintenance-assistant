# 功能设计：推荐问题气泡

## 背景

当前对话界面在消息列表为空时，仅展示一行静态提示文字：

> `请输入问题，例如：B737-800 发动机滑油压力`

项目主要面向无专业机务背景的用户，这种开放式输入框存在两个问题：

1. **认知门槛高**：用户不知道系统能回答什么，也不知道该用什么术语提问。
2. **输入质量不可控**：随意输入会导致向量检索召回率低，影响回答质量。

## 目标

- 通过可点击的推荐问题气泡，降低首次使用成本。
- 用向量数据库中实际存在的机型、系统、手册术语引导用户提问。
- 在视觉上约束用户输入方向，提升检索命中率。
- 通过推荐问题自然触发后端核心能力（路由层、验证层、查询翻译、RAG 检索、流式输出）。

## 方案

在消息列表为空时，于输入框上方展示推荐问题气泡，替换现有静态提示文字。

第一版为**前端静态文案**，不调用后端接口，便于快速验证体验。后续可演进为后端根据上下文动态推荐。

## 用户旅程

```
用户首次进入对话页
    │
    ▼
ProjectGuide 项目介绍弹窗（已有逻辑）
    │
    ▼
关闭弹窗后 / 新建对话后，消息区为空
    │
    ▼
展示「有什么可以帮您？」标题 + 4 个可点击气泡
    │
    ▼
用户点击任意气泡
    │
    ▼
该问题文案自动填入输入框并立即触发发送
    │
    ▼
进入正常流式回答流程
```

## 推荐问题文案

文案设计原则：

- 基于向量数据库实际摄入的文档：CTLS-MM、WT9-AMM、Rotax 912 维护手册、FAA AC 65-9A、FAA-AC-43-13-1B。
- 使用中文提问，触发 `TranslationQueryTransformer` 中译英检索 FAA 英文手册。
- 覆盖关键系统关键词（发动机、滑油、起落架等），触发 `TopicClassifier` 关键系统路由。
- 包含具体机型与发动机型号，触发 `AircraftInfoExtractor` 提取与 `AircraftValidationService` 机型-发动机匹配验证。

| 序号 | 推荐问题 | 触发的主要后端能力 | 命中向量库文档 |
|------|---------|-------------------|---------------|
| 1 | **CTLS 飞机 Rotax 912 发动机滑油压力标准值是多少？** | `TopicClassifier` 关键系统路由、`AircraftInfoExtractor` 提取、`AircraftValidationService` 验证、RAG 检索、流式输出 | CTLS-MM-rev8.pdf、Rotax-912-Line-Maintenance.pdf |
| 2 | **WT9 飞机起落架收放系统的日常检查要求是什么？** | 关键系统路由、提取与验证、RAG 检索、流式输出 | WT9-AMM.pdf |
| 3 | **飞机结构修理中，铆接修理的一般规范有哪些？** | 通用知识路由（不强制机型）、`TranslationQueryTransformer` 中译英、RAG 检索、流式输出 | FAA-AC-43-13-1B.pdf |
| 4 | **B737-800 发动机滑油压力低，应该如何排故？** | 关键系统路由、机型-发动机验证、RAG 检索、流式输出、安全免责声明 | FAA AC 65-9A.pdf |

### 设计意图

- **问题 1 和 2** 针对向量库中有完整 AMM 手册的轻型飞机（CTLS / WT9），展示 RAG 从具体机型手册中检索答案的能力。
- **问题 3** 使用中文询问通用维修标准，展示系统对 FAA 英文手册的跨语言检索能力。
- **问题 4** 针对民航客机场景，展示机型-发动机匹配验证和 FAA 基础教材的通用知识回答能力。不提供发动机型号时，系统会提示补充，这是合理的（B737-800 有多个发动机选项）。

## 交互细节

### 展示时机

- 仅在 `messages.length === 0` 时展示。
- 点击气泡发送后，消息列表不再为空，气泡自动消失。
- 点击「新会话」后，消息列表清空，气泡重新出现。

### 点击行为

- 点击气泡后，将文案写入 `inputText`。
- 自动调用现有的 `sendMessage()` 函数，无需用户再次点击发送按钮或按回车。
- 发送后立即清空输入框（与当前手动发送行为一致）。

### Hover 状态

- 鼠标悬停时气泡轻微上浮（`translateY(-2px)`），并加深边框颜色。
- 光标变为 `pointer`。

### 响应式

- 桌面端：4 个气泡排成 2×2 网格。
- 移动端：单列垂直排列，防止换行混乱。

### 样式规范

- **标题**：`有什么可以帮您？`，字号 18px。
- **气泡卡片**：
  - 背景色 `#f8f9fa`
  - 边框 1px solid `#e0e0e0`
  - 圆角 12px
  - 内边距 16px
  - 文字左对齐
  - 最大宽度 280px
- **Hover 状态**：边框色加深为 `#007bff`，阴影 `0 4px 12px rgba(0,0,0,0.08)`，上移 2px。

```js
const suggestedQuestions = [

  'WT9 飞机起落架收放系统的日常检查要求是什么？',
  '飞机结构修理中，铆接修理的一般规范有哪些？',
  'B737-800 发动机滑油压力低，应该如何排故？'

function sendSuggestedQuestion(question) {
  inputText.value = question
  sendMessage()
}
```

## 验收标准

- [ ] 空状态时，消息区展示「有什么可以帮您？」标题和 4 个推荐问题气泡。
- [ ] 点击任意气泡，该问题被发送，输入框清空。
- [ ] 发送后气泡消失，进入正常流式回答。
- [ ] 点击「新会话」后，气泡重新出现。
- [ ] 桌面端显示为 2×2 网格，移动端显示为单列。
- [ ] 样式与现有主题一致，无视觉突兀感。

## 后续可扩展方向

1. **后端动态推荐**：新增 `/api/suggested-questions` 接口，根据当前会话上下文或向量库热度返回推荐问题。
2. **分类展示**：按「排故」、「手册查询」、「放行」、「功能测试」等维度分组展示。
3. **与 ProjectGuide 联动**：在项目介绍弹窗最后一页增加推荐问题入口。
4. **数据埋点**：统计各气泡点击率，用于优化文案和排序。
